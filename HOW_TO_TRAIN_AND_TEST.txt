================================================================================
                    主实验训练和测试完整流程
================================================================================

【重要】训练前确认
--------------------------------------------------------------------------------
1. 检查配置文件 config.py:
   - TOTAL_VEHICLES = 1800  (车辆数量)
   - NUM_EPISODES = 50      (训练轮数,可根据需要调整)
   - IDLE_THRESHOLD_SEC = 120  (空闲阈值)

2. 确保数据文件存在:
   - data/raw/orders.csv

3. 确保图文件存在:
   - data/processed/neighbor_adj.pt
   - data/processed/poi_adj.pt

   如果没有,先运行: python utils/graph_builder.py


【第1步】训练模型
--------------------------------------------------------------------------------
命令:
    python train.py

或者在后台运行:
    nohup python train.py > train.log 2>&1 &

训练过程:
- 每个episode会显示: Reward, Loss, Epsilon, 完成率, 平均等待时间
- 每1个episode进行一次验证 (VALIDATION_INTERVAL=1)
- 每次验证都会保存模型
- 如果验证性能提升,会打印 "发现新的最佳模型!"
- 如果连续3次验证性能未提升,触发早停 (EARLY_STOPPING_PATIENCE=3)

模型保存位置:
    results/vehicles_1800/models/mgcn_dispatcher_episode_X.pt

    例如:
    - results/vehicles_1800/models/mgcn_dispatcher_episode_1.pt
    - results/vehicles_1800/models/mgcn_dispatcher_episode_2.pt
    - ...
    - results/vehicles_1800/models/mgcn_dispatcher_episode_50.pt


【第2步】测试模型
--------------------------------------------------------------------------------
命令 (自动选择最新模型):
    python test_model.py

或指定模型文件:
    python test_model.py --model results/vehicles_1800/models/mgcn_dispatcher_episode_50.pt

或指定测试episode数:
    python test_model.py --episodes 7

测试过程:
- 加载训练好的模型
- 在测试集上运行7个episode (默认,覆盖最后7天)
- 使用贪婪策略 (epsilon=0.0)
- 输出每天的详细结果和总体平均指标

测试结果保存:
    results/vehicles_1800/logs/results/benchmark_overall_YYYYMMDD_HHMMSS.json
    results/vehicles_1800/logs/results/benchmark_daily_YYYYMMDD_HHMMSS.csv


【常见问题排查】
--------------------------------------------------------------------------------
问题1: 训练时找不到数据
解决: 确保 data/raw/orders.csv 存在

问题2: 训练时找不到图文件
解决: 运行 python utils/graph_builder.py 生成图

问题3: 测试时提示"未找到模型文件"
解决:
- 检查 results/vehicles_1800/models/ 目录是否存在
- 检查目录里是否有 .pt 文件
- 如果没有,说明训练没有完成或保存失败,需要重新训练

问题4: 测试效果比训练时差
可能原因:
a) 使用了错误的模型文件
   - 确认: ls -lht results/vehicles_1800/models/*.pt
   - 使用最新的模型

b) 测试环境没有安装scipy,回退到暴力搜索
   - 确认: python -c "from scipy.spatial import KDTree; print('OK')"
   - 如果失败: pip install scipy

c) 配置参数不一致
   - 确认训练和测试时的config.py相同
   - 特别检查: TOTAL_VEHICLES, MATCHER_KNN_K, MAX_WAITING_TIME

d) 使用了错误的环境文件
   - test_model.py 应该导入: from environment import RideHailingEnvironment
   - 不要用: from environment_baseline import BaselineEnvironment


【检查训练是否成功】
--------------------------------------------------------------------------------
1. 检查模型文件是否生成:
   ls -lh results/vehicles_1800/models/

   应该看到多个 .pt 文件,文件大小应该在几十MB

2. 检查训练日志:
   查看train.py的输出,确认:
   - Loss逐渐下降
   - 完成率逐渐上升
   - 有 "✓ 模型已保存" 的提示

3. 验证模型文件内容:
   python -c "import torch; c=torch.load('results/vehicles_1800/models/mgcn_dispatcher_episode_1.pt', map_location='cpu'); print('Episode:', c['episode']); print('Keys:', list(c.keys()))"

   应该输出: Episode: 1, Keys: ['episode', 'model_state_dict', ...]


【推荐的完整训练流程】
--------------------------------------------------------------------------------
1. 清理旧模型 (可选):
   rm -rf results/vehicles_1800/models/*.pt

2. 确认配置:
   python -c "from config import Config; c=Config(); print(f'TOTAL_VEHICLES={c.TOTAL_VEHICLES}'); print(f'NUM_EPISODES={c.NUM_EPISODES}'); print(f'MODEL_SAVE_PATH={c.MODEL_SAVE_PATH}')"

3. 开始训练:
   python train.py | tee train_$(date +%Y%m%d_%H%M%S).log

4. 训练完成后检查:
   ls -lh results/vehicles_1800/models/

5. 测试模型:
   python test_model.py

6. 查看测试结果:
   cat results/vehicles_1800/logs/results/benchmark_overall_*.json


【时间估计】
--------------------------------------------------------------------------------
- 每个episode训练时间: 约5-10分钟 (取决于硬件)
- 50个episodes总时间: 约4-8小时
- 测试时间: 约30-60分钟 (7个episodes)

建议: 在GPU服务器上训练,CPU上测试
