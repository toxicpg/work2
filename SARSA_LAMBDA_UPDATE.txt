=============================================================================
SARSA(Δ) → SARSA(λ) 算法升级说明
=============================================================================

修改文件: baselines/sarsa_saa.py
修改日期: 2026-02-04

主要变化:
----------

1. 参数变更:
   - 移除: delta (前瞻步数 = 12)
   - 新增: lambda_ (资格迹衰减参数 = 0.9)

2. 数据结构变更:
   - 移除: trajectory_buffer (轨迹缓冲区)
   - 新增: eligibility_traces (资格迹表)
   - 新增: last_state, last_action_value (上一步状态追踪)

3. 核心算法变更:

   旧: SARSA(Δ) - n-step SARSA
   ----------------------------------------
   - 存储最近 Δ=12 步的经验
   - 延迟 12 步后更新 Q 值
   - 使用累积奖励 G_t = Σ(γ^i * r_i)
   - 内存开销: O(Δ)

   新: SARSA(λ) - 标准资格迹算法
   ----------------------------------------
   - 维护所有状态的资格迹
   - 每步更新所有有资格迹的状态
   - TD误差: δ = R + γQ(S',A') - Q(S,A)
   - 资格迹衰减: e(s) *= γλ
   - 内存开销: O(已访问状态数)

4. 更新逻辑对比:

   SARSA(Δ):
   ```python
   if len(buffer) > 12:
       past_state = buffer[0]
       G = Σ(γ^i * reward_i)  # 累积12步奖励
       Q[past_state] += α * (G - Q[past_state])
   ```

   SARSA(λ):
   ```python
   δ = R + γQ(S',A') - Q(S,A)  # TD误差
   e[S] += 1                    # 增加当前状态资格迹
   for all states s:
       Q[s] += α * δ * e[s]     # 更新所有状态
       e[s] *= γλ               # 衰减资格迹
   ```

5. 新增方法:
   - reset_episode(): 每个 episode 开始时重置资格迹

6. 推荐参数:
   - λ = 0.9 (平衡短期和长期奖励)
   - α = 0.1 (学习率)
   - γ = 0.99 (折扣因子)

优势:
-----
✓ 更快的学习速度 (一次更新多个状态)
✓ 更好的信用分配 (Credit Assignment)
✓ 理论基础更扎实 (经典 RL 算法)
✓ λ 参数可调节短期/长期权衡

使用方法:
---------
训练:
  python run_sarsa_saa.py --vehicles 1800 --rounds 5

测试不同 λ 值:
  修改 baselines/sarsa_saa.py 第 592 行:
  agent = SarsaSAABaseline(config, lambda_=0.9, sample_size=7)

  可尝试: λ = 0.0, 0.5, 0.9, 1.0

λ 参数说明:
-----------
λ = 0.0: 标准 SARSA (只看一步, 学习快但短视)
λ = 0.5: 中等记忆 (平衡)
λ = 0.9: 长期记忆 (推荐, 考虑长远)
λ = 1.0: Monte Carlo (看整个 episode, 学习慢但全局)

参考文献:
---------

- Yan et al. (2023). EJOR. (原始 SAA-SARSA 论文)
