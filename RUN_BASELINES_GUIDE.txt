                    对比实验运行指南 (Baseline Experiments)
═══════════════════════════════════════════════════════════════════════════

📋 实验配置:
  - 车辆数量: 1800, 2000, 2200
  - Baseline方法: 5个 (Random Walk, Random Dispatch, SARSA-SAA, H-MARL, CNN-DDQN)
  - 早停机制: 连续3次未提升自动停止

─────────────────────────────────────────────────────────────────────────

🚀 方法1: 一键运行所有实验 (推荐)
─────────────────────────────────────────────────────────────────────────

python run_baselines_all_vehicles.py

✓ 自动处理1800/2000/2200三种车辆数量
✓ 自动运行所有5个baseline方法
✓ 结果保存到 results/vehicles_{车辆数}/baselines/
✓ 预计总耗时: 根据早停机制，可能需要数小时

─────────────────────────────────────────────────────────────────────────

🎯 方法2: 手动运行单个baseline
─────────────────────────────────────────────────────────────────────────

1. 修改 config.py 中的 TOTAL_VEHICLES:
   TOTAL_VEHICLES = 1800  # 或 2000, 2200

2. 运行对应的baseline脚本:

   # Random Walk (不需要训练，直接测试)
   python baselines/random_walk.py

   # Random Dispatch (不需要训练，直接测试)
   python baselines/random_dispatch.py

   # SARSA-SAA (包含训练+测试)
   python baselines/sarsa_saa.py

   # H-MARL (包含训练+测试)
   python baselines/train_hmarl.py

   # CNN-DDQN (包含训练+测试)
   python baselines/cnn_ddqn.py

3. 重复步骤1-2，修改车辆数量并重新运行

⚡ 早停机制说明
─────────────────────────────────────────────────────────────────────────

所有baseline现在都有早停机制(patience=3):
  - CNN-DDQN: 监控训练奖励，连续3个episode未提升则停止
  - SARSA-SAA: 每3天检查Q表进度，连续3批次未提升则停止
  - H-MARL: 监控episode奖励，连续3个episode未提升则停止
  - Random Walk/Dispatch: 无需训练，直接测试

这会显著减少训练时间！

─────────────────────────────────────────────────────────────────────────

⏱️ 预计运行时间
─────────────────────────────────────────────────────────────────────────

单个车辆配置 (取决于早停触发时机):
  - Random Walk: 约10-15分钟
  - Random Dispatch: 约10-15分钟
  - SARSA-SAA: 约30-60分钟 (有早停)
  - H-MARL: 约20-40分钟 (有早停)
  - CNN-DDQN: 约30-50分钟 (有早停)

总计 (3个车辆配置): 约5-9小时

─────────────────────────────────────────────────────────────────────────

💡 建议
─────────────────────────────────────────────────────────────────────────

1. 使用 tmux 或 screen 运行长时间实验，避免网络断开
2. 可以先运行一个车辆配置测试流程是否正常
3. 查看实时输出，确认早停是否正常工作
4. 实验完成后检查 results/ 目录确认所有结果已保存
