【实验设计】

实验1: 均匀分布 × 不同车辆数
  - 车辆数: 1800, 2000, 2200
  - 分布: 均匀随机分布
  - 天数: 最后7天
  - Baseline: Random Walk + Random Dispatch

实验2: 不同初始分布 × 固定车辆数
  - 车辆数: 2000
  - 分布: 正态分布 (σ=1, 3, 5, 7)
  - 天数: 1天（最后一天）
  - Baseline: Random Walk + Random Dispatch

【记录指标】
  ✓ 等待时间 (avg_waiting_time)
  ✓ 匹配率 (match_rate)
  ✓ 完成率 (completion_rate)
  ✓ 取消率 (cancel_rate)

================================================================================
  ⚙️ 关键参数说明
================================================================================

Baseline 环境配置 (environment_baseline.py):
────────────────────────────────────────────────────────────────────────────
- 匹配距离限制: 3格 (曼哈顿距离)
- 冷启动机制: 初始所有车辆serving，1-10分钟内随机释放
- 冷却机制: 完成订单后需等待当前tick结束才能再次接单

Random Walk:
────────────────────────────────────────────────────────────────────────────
- 空闲阈值: 300秒 (5分钟)
- 动作: 随机移动到相邻格子 (上/下/左/右/停留)

Random Dispatch:
────────────────────────────────────────────────────────────────────────────
- 空闲阈值: 300秒 (5分钟)
- 动作: 随机调度到179个全局热点格子之一

车辆分布生成:
────────────────────────────────────────────────────────────────────────────
- 均匀分布: rng.integers(0, 400, num_vehicles)
- 正态分布: 中心(9.5, 9.5), 标准差σ, 裁剪到[0,19]

================================================================================
  🐛 常见问题
================================================================================

Q1: 匹配率太低(<20%)或太高(>90%)
────────────────────────────────────────────────────────────────────────────
A: 检查 environment_baseline.py 中的距离限制:
   grep "manhattan_distance > 3" environment_baseline.py
   应该看到: if manhattan_distance > 3: continue

Q2: Random Dispatch 没有执行调度
────────────────────────────────────────────────────────────────────────────
A: 检查方法是否存在:
   grep "_execute_random_dispatch_to_hotspots" environment_baseline.py

Q3: 实验运行时间太长
────────────────────────────────────────────────────────────────────────────
A: 可以分别运行实验1和实验2:
   python run_baseline_experiments.py --exp 1  # 只跑实验1
   python run_baseline_experiments.py --exp 2  # 只跑实验2

Q4: 内存不足
────────────────────────────────────────────────────────────────────────────
A: 减少车辆数或分批运行
